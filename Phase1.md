Fabulari is a real-time chat application developed as part of the 3813ICT assignment, built on using systems such as Angular and Node.js powering live communication. Similar to platforms like WhatsApp or Discord, it allows users to exchange text and image messages instantly, while supporting group structures for organising conversations. The application also includes role-based administrative functionality, allowing privileged users to manage tasks such as approving new user creation requests and assigning users to groups and channels. Development follows a git-driven workflow, with frequent commits demonstrating the project's progress from initial design through to full implementation across its two phases.

The branching strategy will follow GitFlow, using "main" and "develop" as the two core branches. The "main" branch will hold the finalised, submission-ready state of the project (including the report and documentation), while "develop" will act as the integration branch for ongoing work. Feature branches will be created off "develop" for individual streams of work, such as "Wireframes" for the UI wireframe elements and "Web Application" for the actual application code, before being merged back into "develop" and eventually into "main".
